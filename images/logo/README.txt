The mark - "the lensed x"
=========================

Source of truth is the logo project, not this folder:

    ../../../logo/final/        the files, regenerated by ../../../logo/final.py
    ../../../logo/final/USAGE.md   which file goes where, clear space, minimums

Never edit these SVGs by hand. Change a proportion at the top of final.py
(arc radius, arm lengths, arc spans, the clearance before the x), run
`python3 final.py`, and copy the results here again.

Where it is used on this site
-----------------------------

  index banner       images/logo/bakx-lockup-dark.svg  the name itself, inside the
                                                      h2 (alt text keeps it a heading)
  fixed header bar   images/logo/bakx-icon-dark.svg   left of "Tom Bakx", every page
  footer             images/logo/bakx-icon-dark.svg   above the link list, all 7 pages
  CV                 images/logo/bakx-icon.svg        above the contact block
  CSFRD figure       drawn inline in index.html       signature in the lower right,
                                                      white at 42% - travels with
                                                      the figure into talks
  404 page           images/logo/bakx-icon.svg        the one page it gets to be
                                                      the content (404.html uses
                                                      absolute paths: GitHub Pages
                                                      serves it from any depth)
  browser tab        /favicon.ico, /favicon.svg
  iOS home screen    /apple-touch-icon.png
  Android            /site.webmanifest -> /icon-192.png, /icon-512.png
  Safari pinned tab  images/logo/bakx-icon-mask.svg

Styling lives in assets/css/logo.css, linked from every page. The header bar
and the footer are both ink (#2e3842 / #1d242a), which is why they take the
dark file - white arcs, red x. The CV is on paper, so it takes the light one.
