game/assets/sky/ — celestial landmarks for the whole-sky view

Generated by scripts/export_sky.py on 2026-08-31. Do not edit by hand; edit the
script and rerun it. The game makes no network requests: these files are baked
in at export time.

Raw catalogues (cached in data/sky/, re-downloadable with --fetch) come from
d3-celestial by Olaf Frohn, MIT licence:
  https://raw.githubusercontent.com/ofrohn/d3-celestial/master/data
which in turn derives from
  stars.6.json, starnames.json   Hipparcos / Yale Bright Star Catalogue, to V=6
  constellations.lines.json      IAU constellation stick figures
  milkyway.json                  Milky Way isophote contours, 5 levels

milkyway.png (1440x720 RGBA, 76 kB)
    Plate-carree glow raster in the game's *world* pixels: image x runs with
    world x = (360 - RA) mod 360, image row 0 is Dec = +90. Alpha is the
    accumulated brightness of the five nested contour levels (weights
    ol1=0.2, ol2=0.2, ol3=0.2, ol4=0.2, ol5=0.2), even-odd filled so inner rings cut holes, wrapped in RA, then
    smoothed with a 3.0 px (0.75 deg) Gaussian and gamma 1.15.
    RGB is a flat pale blue-white (198, 212, 245); the game tints nothing, it just sets
    globalAlpha. Drawn with one drawImage per visible 360 deg copy.

stars.json (5044 stars, 123 kB)
    Parallel arrays sorted brightest first: ra, dec (degrees, J2000), mag
    (V, limit 6.0), bv (B-V colour index, 0.6 where the catalogue has
    none). "names" pairs an index with a proper name, for the 99 named
    stars brighter than V = 2.6.

constellations.json (150 polylines, 89 labels, 17 kB)
    "lines" are [[ra, dec], ...] polylines in degrees; a polyline may cross
    RA = 0 and the renderer unwraps it. "labels" carry name, ra, dec and the
    IAU rank (1 = the prominent figures, used to decide what gets a label).
